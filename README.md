# KROM releases

Installers and auto-update feeds for **KROM** (Kromatic Relational Operations Manager), a desktop database manager for PostgreSQL, MySQL/MariaDB, SQLite, SQL Server and MongoDB.

Download the file for your system from the [Releases](../../releases) page. `SHA256SUMS-*.txt` lists checksums.

This repository only hosts release files; it is written by CI.
